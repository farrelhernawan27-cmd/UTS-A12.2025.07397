01 / TENTANG WORKSHOP

Punya ide?
Beri ruang di web.

Kamu tidak harus langsung membuat sesuatu yang rumit. Mulai dari satu halaman yang punya tujuan, tampilan yang rapi, dan interaksi yang membantu pengunjung.

Di Web Starter Day, kamu akan berlatih membuat landing page acara dari awal. Cocok untuk mahasiswa yang sedang mengenal HTML, CSS, dan JavaScript dasar.

Intip alur belajarnya ↗

02 / YANG AKAN KAMU PELAJARI

Tiga fondasi.
Banyak kemungkinan.

Pelajari perannya, lalu satukan
menjadi satu halaman yang utuh.

01</>

HTML

Susun ceritanya.

Bangun struktur konten dengan elemen semantik agar halaman teratur dan mudah dipahami.

  • Header, main, section, footer
  • Link, gambar, dan formulir
  • Struktur heading yang runtut
02{ }

CSS

Bentuk tampilannya.

Atur layout, warna, dan tipografi. Buat halaman tetap nyaman di laptop maupun ponsel.

  • Flexbox dan CSS Grid
  • Spacing dan konsistensi visual
  • Media query untuk mobile
03( )

JAVASCRIPT

Hidupkan interaksinya.

Hubungkan aksi pengguna dengan perubahan pada halaman melalui DOM dan event listener.

  • Variabel, kondisi, dan fungsi
  • Seleksi dan manipulasi DOM
  • Event click dan submit
